# TypeScript Learning Project: Task Management System

A comprehensive TypeScript learning project designed for developers with C/C++ and Python background.

## Project Overview

You'll build a complete task management application while learning all major TypeScript concepts. Each task focuses on specific TypeScript features and builds upon previous knowledge.

## Learning Path

### **Task 1: Basic Types & Functions** (30 mins)
- **File**: `task1.ts`
- **Concepts**: Primitive types, arrays, tuples, function signatures
- **README**: `task1/README.md`

### **Task 2: Interfaces & Object Types** (30 mins)
- **File**: `task2.ts`
- **Concepts**: Interface definitions, optional properties, extending interfaces
- **README**: `task2/README.md`

### **Task 3: Classes & OOP** (45 mins)
- **File**: `task3.ts`
- **Concepts**: Classes, inheritance, access modifiers, abstract classes
- **README**: `task3/README.md`

### **Task 4: Generics** (30 mins)
- **File**: `task4.ts`
- **Concepts**: Generic functions/classes, type constraints
- **README**: `task4/README.md`

### **Task 5: Advanced Types** (45 mins)
- **File**: `task5.ts`
- **Concepts**: Union/intersection types, type guards, literal types
- **README**: `task5/README.md`

### **Task 6: Modules & Organization** (30 mins)
- **Files**: Multiple module files
- **Concepts**: ES6 imports/exports, module resolution
- **README**: `task6/README.md`

### **Task 7: Async Programming** (45 mins)
- **File**: `task7.ts`
- **Concepts**: Promises, async/await, error handling
- **README**: `task7/README.md`

### **Task 8: Advanced Types & Utilities** (45 mins)
- **File**: `task8.ts`
- **Concepts**: Utility types, mapped types, conditional types
- **README**: `task8/README.md`

## Getting Started

1. Start with Task 1: `cd task1 && cat README.md`
2. Complete each task in order
3. Test your work: `npx ts-node taskX.ts`
4. Ask questions as needed!
